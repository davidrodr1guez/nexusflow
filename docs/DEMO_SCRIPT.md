## Technical Notes for Recording

1. **Browser:** Use Chrome, clear cache
2. **Wallet:** MetaMask with Sepolia testnet
3. **Resolution:** 1920x1080
4. **Audio:** Clear mic, no background noise
5. **Speed:** Don't rush — let transactions confirm on screen
